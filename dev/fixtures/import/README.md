# Fictional importer fixtures

Every HTML page in this directory is written for Spoonfuls and uses `example.test`
URLs. Nothing is copied from a real recipe site.

- `01`–`03`: WordPress-style JSON-LD, `@graph`, and microdata-only pages.
- `04`–`05`, `12`–`13`: missing, broken, and partial metadata.
- `07`–`11`, `14`: HowTo sections, ISO durations, nutrition, multiple images, and UTF-8/Latin-1 non-English text.
- `06`: the target served after a local redirect in `test_fetch.py`; the redirect chain is
  generated by that local server so it never contacts the internet.
- The huge-page case is generated by repeating the fixture shell in the limit test;
  committing a megabyte of filler would add no parser coverage.
