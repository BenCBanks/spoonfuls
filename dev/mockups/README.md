# Visual direction mockups

These are static owner-preview pages for issue #4. Each page contains the same
Cookbook home, Recipe page, and Save sheet in a direction-specific palette and
type treatment. Set `body[data-theme]` to `light` or `dark` and capture one
`section[data-screen]` at a 390 px viewport for the review set.

- `herb-garden.html` — cool off-white and deep green palette.
- `blueberry.html` — cool off-white and deep blue/indigo palette.
- `stone-plum.html` — warm grey neutrals and deep plum palette.

All recipe names, author names, counts, and imagery are fictional. Food imagery
is made from CSS gradients and shapes; no stock or personal photos are used.
